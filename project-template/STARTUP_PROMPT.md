# AI engineering startup prompt

Copy the prompt below into a new project's AI chat and attach the
[AI engineering foundation](AGENTS.md).

```text
Set up this project using the AI engineering foundation in AGENTS.md (attached or present in this repository).

Inspect the repository first, then create or update AGENTS.md using the
foundation as the shared engineering standard. Preserve existing project
rules and flag any conflicts.

Fill in project-specific details from the actual code and approved requirements.
Mark unknowns explicitly. Keep the foundation platform-neutral and place detailed
technology or domain guidance in linked documents.

Apply the solo development review policy: author review and verification for
routine changes, a separate AI review pass for substantial changes when available,
and another qualified human reviewer for high-risk changes. Record review gaps
honestly.

Establish or document reproducible setup and verification commands appropriate
to this project. Preserve existing behavior, dependencies and unrelated work.
For an empty repository, ask for the product goal and critical technology choices
before selecting a stack.

Complete the authorized setup, run appropriate checks, and summarize changes,
results and unresolved decisions. Do not commit, push or deploy without explicit
authorization.
```
