API and geometry reference

Named signals expose value, quality, timestamp and unit. Use quality before calculating. The appearance API supports helpers.clamp(value, min, max) and returns declared properties: 

{{
          '{ text: "Ready", color: "#329c8c", position: { offsetX: 0, offsetY: 0 }, rotation: { offsetDegrees: 0 } }'
        }}

Position offsets are screen pixels from saved geometry; rotation is a degree offset around the saved center. Out-of-screen geometry fails. No browser, network, clock, random or device action API is exposed to appearance scripts.
